nREPL Compatibility Matrix

Here's how the servers below fare against the checks of proof, which are mostly about what the clients people use (CIDER, Calva, Conjure, vim-fireplace, REPLy and so on) need from a server.

pass
The server does what the clients need.
fail
Some client won't work properly with the server, or users lose data.
warn
The server does something differently from nREPL or the spec, but no client we know of minds.
skip
The check doesn't apply to the server (e.g. it needs Java interop).
error
proof couldn't run the check.

Hover over a check to see why it matters, and over a verdict for the details.
